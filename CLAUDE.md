# Peak (garmin-client)

Personal Garmin Connect client: activities, sleep, health and training from the Garmin Connect Personal API.
Same stack, structure, look and animations as `../winner` (Winner for Life).

## Working rules
- Talk to the owner in **Italian**, simple explanations. Everything in the app and code (UI text, names, comments, commits) in **English**.
- Never commit secrets. `.env` is gitignored; document variables in `.env.example`.
- Local commits only unless the owner asks to push.

## Stack
- Vite + React 19 + TypeScript + Tailwind v4, react-router 7, lucide-react, font Manrope.
- Data access goes through `src/data/repo.ts` (`Repo` interface). Screens never talk to a backend directly.
  - `localRepo` — demo backend: accounts/settings in localStorage, Garmin data generated by `src/data/demoSeed.ts` (deterministic per user + date).
  - Supabase is **not connected yet**: add `supabaseRepo` next to `localRepo` and pick it in `repo.ts` when env vars are set.
- Pure logic in `src/domain/` (unit tested): training load, status, race predictor, zones, stats, records.
- Metric catalog (labels, colors, how to read each value) in `src/config/metrics.ts`; sports in `src/config/sports.ts`; badges in `src/config/badges.ts`.
- Dates: plain `YYYY-MM-DD` in the user's timezone (`src/lib/dates.ts`, copied from winner). A sleep night belongs to the wake-up date.
- Units: always store metric; format with `unitFormat(units)` / `useUnits()` (`src/lib/format.ts`).

## Commands
- `npm run dev` — dev server
- `npm test` — unit tests (vitest)
- `npm run build` — typecheck + production build
- `npm run lint` — eslint
